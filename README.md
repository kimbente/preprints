## Towards a Geospatial Foundation Model for Antarctica

The following points should still be extended:
- Clarify the scope of this work. For now these ideas focus on proposing a land-based (i.e. continental) Antarctic geospatial foundation model and thus are more concerned with spatial representation learning that spatio-temporal representation learning.
- Examples of supervised models for Antarctica should thus also focus on the Antarctic continent rather than the Antarcic ocean or the polar region more broadly.
- Return period of the data set should be included in the table.
- Justifications for the need of a geospatial FM for Antarctica should be compatly stated in one paragraph.
- Ideas regarding the integration of multi-modal data sets should be discussed in more detail. Fourier methods or multi-scale methods should be discussed.
- Potentially other well known techniques in addition to MAE and CLIP, like DINOv2, can be mentioned, although previous work demonstrated that this was not the favourable SSL model choice.
- Models like Satlas by AllenAI (AI2) should maybe be mentioned, and why this segmentation-driven approach is less relevant to the suit of target tasks.
